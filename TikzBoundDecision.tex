\caption{What may be reported as a lower bound. A quantity above a
solution one can exhibit is not a loose bound but a false statement,
and it inflates every optimality gap computed from it. The final test
is a falsifiability check rather than a proof step: on one instance the
Lagrangian value $21552.23$ survived every internal consistency check
while that run's own pool admitted a verified, slack-free plan costing
$21502.80$ --- the restricted master lies above the true optimum too,
so nothing inside the run contradicts it.}
